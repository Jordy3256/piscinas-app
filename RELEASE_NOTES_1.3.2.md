# JVAQUA ERP 1.3.2 — Release Notes

## Novedades

- Centro de Acciones como escritorio del administrador.
- Bloques de cobros, facturación, nómina, operación y programación.
- Acciones rápidas para crear clientes, contratos, registrar cobros y pagar nómina.
- Resumen diario y actividad reciente.

## Compatibilidad

No se modifican modelos ni migraciones. Se conserva toda la lógica actual de contratos, cartera, nómina y mantenimientos.

## Pruebas recomendadas

1. Abrir `/dashboard/inicio/` como administrador.
2. Verificar cobros vencidos y del día.
3. Abrir un pago de factura desde el botón Cobrar.
4. Abrir el pago consolidado de un trabajador.
5. Revisar mantenimientos de hoy y atrasados.
6. Confirmar la visualización móvil.
