JVAQUA v3.6.2 - Usabilidad Operativa

1. JVAQUA Digital
- Botón Salir visible en móvil en encabezado y navegación inferior.

2. Fotografías de mantenimientos
- Detectado: MEDIA usa almacenamiento local. En Render ese almacenamiento no es persistente entre deploys.
- Se agregó soporte automático para Cloudinary cuando exista la variable CLOUDINARY_URL.
- Sin CLOUDINARY_URL el comportamiento local actual se conserva.

3. Operativo Admin
- Calendario/agenda pasan a segundo plano y quedan ocultos inicialmente.
- Botón para desplegar programación cuando sea necesaria.
- KPIs y operación diaria quedan antes que la programación completa.

4. Mis Mantenimientos trabajador
- Calendario/agenda quedan ocultos inicialmente.
- Hoy, ruta sugerida y operación diaria quedan visibles primero.
- Botón compacto para consultar calendario/programación.

No requiere migraciones.
