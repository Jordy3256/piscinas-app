# JVAQUA ERP v1.3.3 — Nómina con periodos de servicio

- El trabajador puede descargar su PDF mensual de nómina desde Mi Cuenta.
- Cada obligación guarda históricamente las fechas de inicio y fin del servicio.
- Las fechas aparecen en Nómina, detalle, pagos consolidados y PDFs.
- Los periodos históricos no se alteran al modificar posteriormente un contrato.
