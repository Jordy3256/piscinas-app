# JVAQUA ERP 3.1.0 - Academia JVAQUA CMS

- CMS administrable para Biblioteca Técnica, Procedimientos y Equipos.
- Flujo Borrador / Aprobado / Archivado.
- Insignia de Conocimiento Oficial JVAQUA.
- Editor estructurado por bloques.
- Imagen principal y galería ilustrativa.
- Relaciones entre contenidos.
- Etiquetas y búsqueda de texto.
- Historial de versiones con motivo del cambio.
- Base de Conocimiento interna y conversión controlada a borrador oficial.
- PDFs por artículo, categoría y Manual Técnico completo.
- Vista del trabajador limitada exclusivamente a contenido aprobado.
- El Asistente Técnico continúa funcionando como una sola herramienta.
